# Frontend

React + TypeScript + Vite + Tailwind + shadcn/ui.

## Owner
Alan Herrera

## Pages
- `/` - Dashboard
- `/subscriptions` - List of active subscriptions
- `/cases/:id` - Case timeline
- Decision card (modal, triggered on `/cases/:id` when state = `awaiting_human`)

## Setup
```bash
cd frontend
npm install
npm run dev
```
